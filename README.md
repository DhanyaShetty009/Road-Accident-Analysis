# Power BI Data Analysis Project

This repository contains a Power BI project focused on data visualization and business intelligence. The goal is to provide meaningful insights through interactive dashboards created using Power BI.

---

## Project Overview

The Power BI report includes analysis such as:

- Time-based performance trends
- Category and sub-category breakdowns
- Customer or user behavior insights
- Regional or location-based comparisons
- KPIs highlighting key business metrics

This project demonstrates the use of Power BI for data import, modeling, DAX-based calculations, and dashboard design.

---

## File Included

- `project.pbix`: Power BI Desktop file containing the full data model, calculated measures, and interactive report visuals.

> **Note**: You need **Power BI Desktop** installed to open and interact with the `.pbix` file.

---

## Tools Used

- **Power BI Desktop**
  - Data Modeling
  - DAX (Data Analysis Expressions)
  - Interactive Visualizations
  - Slicers & Filters
  - Charts (Bar, Line, Pie, Matrix, etc.)
